# Cerdas Cermat Kebangsaan — Mode Pertandingan

- 12 paket dan 100 soal.
- Empat pilihan jawaban per soal (satu benar, tiga pengecoh otomatis dari bank jawaban).
- Semua soal memakai satu timer 1 menit 30 detik. Timer terus berjalan saat pemain menjawab maupun berpindah soal; tingkat kesulitan tidak mengubah waktu.
- Benar: +10 poin (mudah) atau +15 poin (sulit); salah: 0 poin.
- Tombol pilihan bergoyang dan jatuh saat ditekan.
- Salah: animasi retak/kilat lembut dan teks “NKRI LO MANA?”.
- Benar: kilau bintang sekitar 3 detik dan teks “GOKIL!”.
- Waktu habis: tampil tulisan “LELET BANGET SUMPAH LO” selama 3 detik, lalu kembali ke menu utama. Akhir paket: blok merah menyapu layar dan tulisan “Tetap Semangat!”.
- Paket berikutnya masuk dengan fade-in 1,5 detik.
- Tema merah putih, responsif.

## Menjalankan
Ekstrak ZIP, buka folder di VS Code, lalu buka `index.html` di browser (atau gunakan Live Server).

Catatan: pilihan pengecoh diambil otomatis dari jawaban lain di bank soal. Untuk membuat pilihan yang lebih kontekstual, edit pilihan di `app.js`.
